# 🚀 AI Space Explorer

AI Space Explorer is a fully animated interactive web application that allows users to explore planets, the Solar System, famous space missions, galaxies, black holes, and space travel concepts through a modern visual interface.

The project also includes a built-in AI space assistant called **SPACE AI**, which can answer astronomy-related questions using either Demo Mode or an OpenAI-powered backend.

---

## 🌌 Project Overview

AI Space Explorer was created as an interactive educational and portfolio project combining:

- Modern frontend development
- Full-stack web development
- Interactive animations
- Astronomy education
- AI integration
- Responsive design
- API communication

The application provides an immersive experience where users can explore different parts of the universe through animated sections and interactive controls.

---

# ✨ Features

## 🌍 Planet Explorer

Explore all 8 planets of the Solar System.

Each planet includes:

- Planet name
- Distance from the Sun
- Average temperature
- Diameter
- Number of moons
- Orbital period
- Description
- Animated planet preview

Supported planets:

- Mercury
- Venus
- Earth
- Mars
- Jupiter
- Saturn
- Uranus
- Neptune

---

## ☀️ Interactive Solar System

The project includes an animated Solar System simulation.

Features include:

- All 8 planets orbiting the Sun
- Different orbital speeds
- Pause and resume simulation
- Slow orbit mode
- Normal orbit mode
- Fast orbit mode
- Smooth orbit continuation
- Clickable planets
- Planet information modal
